# Michael Liu GitHub Pages Site

Static one-page portfolio for GitHub Pages.

## Local Preview

Open `index.html` in a browser.

## Publish

Create a GitHub repository named:

```text
Michael-Full-Stack-Liu.github.io
```

Then put these files in the repository root:

```text
index.html
styles.css
README.md
```

GitHub Pages will publish the site at:

```text
https://Michael-Full-Stack-Liu.github.io
```
